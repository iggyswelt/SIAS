# Changelog

All notable changes to SIAS are documented here.

## [3.2] — 2026-04-13

### Added
- **arthemis** — QA & Architect agent
- Dreaming mode for offline self-improvement
- Rheingold standalone mode with own database
- Inter-Agent Bridge for direct agent communication
- Event chains for multi-agent workflows

## [3.1] — 2026-04-08

### Added
- Dashboard V2 with real-time monitoring
- ICA Log Watcher (Inter-Agent Chat)
- Hestia YouTube pipeline
- OpenClaw 4.8 compatibility

### Changed
- Improved backup process (depersonalized)

## [3.0] — 2026-04-07

### Added
- 3 Worker Services (Hermes, Rheingold, Hestia)
- Event Chain architecture
- Worker process management
- SIAS Core API enhancements

## [2.0] — 2026-04-05

### Added
- Redis Event Bus for inter-agent communication
- SIAS Core API (FastAPI)
- PostgreSQL as single source of truth
- Agent knowledge database schema

### Changed
- Migrated from direct messaging to event-driven architecture

## [1.0] — 2026-04-01

### Added
- Initial SIAS architecture
- Base agent framework on OpenClaw
- metamaus, apollon, rheingold, pythia, orpheus agents
- Basic inter-agent communication
- First documentation (README DE/EN)
